## 0) Product Rule Card

1) **Я делаю продукт для:** фаундера-сольщика, который планирует неделю «в голове», а к пятнице не понимает — двигался ли он в нужную сторону или просто тушил пожары
2) **Их боль:** планы амбициозные, отчётность — нулевая. Неделя уходит, а честный ответ «что сделал и что из этого важного» — трудно дать самому себе
3) **Мой результат:** бот ведёт три диалога: недельное планирование (вопросы → GPT-план), ежедневная рефлексия (вопросы → GPT-ответ), недельный обзор (данные за неделю → GPT-ответ). Пользователь видит движение по плану
4) **Мой "вау-момент" за 30 секунд:** недельный обзор: «Вот твой план. Вот что сделано. Движение по главному фокусу — 60%.»
5) **За что платят:** за систему, которая фиксирует план, собирает факты за неделю и возвращает GPT-анализ: план vs факт, движение по цели

## 1) Pain Inventory

### Боль №1 — «План был, а что реально сделал — не помню»
- **Боль (фразой человека):** «В понедельник знал, что надо сделать. В пятницу — ощущение, что бегал как белка в колесе, но прогресса нет.»
- **Триггер:** конец недели, попытка подвести итоги. План — в заметках или в голове. Факты — размыты
- **Цена промедления:** иллюзия движения → реальные цели не сдвигаются → burnout от «работаю много, но не туда»
- **Альтернативы:** Notion, weekly review в блокноте, еженедельные созвоны с софаундером
- **Почему не сработало:** review делаю нерегулярно. Блокнот — нет структуры. Софаундер — не видит твои внутренние приоритеты
- **Победа:** бот в воскресенье задаёт вопросы → возвращает структурированный план. В субботу собирает ответы за неделю → GPT даёт «что сделано vs план»

### Боль №2 — «Нет структуры для честной оценки»
- **Боль (фразой человека):** «Хочу понимать, двигался ли я. Но некуда записать план, некуда собрать факты.»
- **Триггер:** попытка ответить себе «что сделал за неделю»
- **Цена промедления:** самообман или полное игнорирование итогов недели
- **Альтернативы:** блокнот, spreadsheets, «держу в голове»
- **Почему не сработало:** нет связи между планом и фактами. Нет формата. Забрасываю
- **Победа:** план зафиксирован в воскресенье. Факты собираются через рефлексию. обзор автоматически сопоставляет план и факт

### Боль №3 — «Ежедневная рефлексия — скучная рутина»
- **Боль (фразой человека):** «Пробовал вести дневник. Через неделю забросил — тратил время, а инсайтов ноль.»
- **Триггер:** конец дня, усталость. Писать в пустоту не хочется
- **Цена промедления:** нет сырых данных для недельного обзора → обзор невозможен
- **Альтернативы:** дневник, Day One, развёрнутые заметки
- **Почему не сработало:** открытая форма — барьер. Длинные ответы — устаёшь. Нет обратной связи
- **Победа:** бот задаёт 3–5 коротких вопросов (1–2 мин). GPT возвращает компактный ответ. Данные идут в недельный обзор. Есть «ответ», не просто запись

## 2) Context Map

- **Ситуация (где/когда):** воскресенье — планирование (5-10 мин). Каждый вечер — рефлексия (1–3 мин). Суббота — недельный обзор (1-3 мин). Telegram как основной канал
- **Эмоция:** по воскресеньям — надежда («вот эта неделя»). По вечерам — усталость, иногда вина («мало сделал»). По субботам — любопытство («что покажет обзор?»)
- **Барьеры:** «не хочу ещё один бот». «GPT — общие слова». «Данных мало — обзор будет пустой»
- **Альтернативы:** проигнорировать напоминание / записать в блокнот / «и так помню»
- **Победа:** план в воскресенье → ответы на рефлексию каждый день → субботний обзор: план vs факт. Движение измеримо
- **Канал:** Telegram (все три потока).

## 3) Persona Schema

- **Кто он:** фаундер-сольщик или ранний софаундер. 1–5 человек в команде. Product/tech/business. 25–45 лет. Нет отдельного PM/коуча
- **Цель:** измерять движение по недельному плану. Честная картина без самообмана
- **Страх:** «система покажет, что я ничего не делаю». «Ещё одна рутина, которую заброшу». «GPT наговорит общих фраз»
- **Победа:** недельный обзор показывает: план, факты, движение по главному фокусу. «Теперь вижу, что сделал vs что планировал»
- **Провал:** бот требует слишком много ввода. GPT возвращает банальности. обзор пустой из-за нехватки данных
- **Что пробовал:** Notion, дневники, weekly review вручную, «держу в голове»
- **Его слова/цитаты:**
  - «Планирую хорошо. Выполняю — как получается»
  - «К пятнице не помню, что планировал в понедельник»
  - «Хочу честную картину без самооправданий»

## 4) Value Contract

- **Обещание:** три диалога в Telegram. Недельное планирование — бот задаёт вопросы, GPT возвращает план. Ежедневная рефлексия — короткие вопросы, GPT-ответ. Недельный обзор — бот собирает данные за неделю, GPT возвращает план vs факт, движение по цели
- **Анти-обещание:** это не таск-менеджер, не Gantt, не командный трекер. Не заменяет стратегию. Не обещает «всё успеешь»
- **Критерий результата:** время на рефлексию <3 мин. Недельный обзор содержит план vs факт. Пользователь может ответить «что сделал vs план» за неделю
- **Time-to-Wow:** первый недельный обзор — «Вот твой план. Вот факты. Вот движение.» Честная картина, которую не получал вручную
- **Почему сейчас:** фаундеры планируют, но не измеряют. Ручной обзор — трудозатратен. GPT + структурированные данные дают обзор за минуты

## 6) Trust Checklist

- **Данные:** планы (недельные), ответы на рефлексию, GPT-ответы, llm_calls (модель, токены, latency)
- **Хранение/срок:** пока аккаунт активен
- **Удаление:** полное удаление по запросу. Экспорт перед удалением
- **Контроль:** пользователь редактирует план. Может пропустить рефлексию. обзор — информация, не приговор
- **Запрещено:** не удалять данные без запроса. Не показывать обзор без достаточного количества данных (предупреждать)
- **Ошибки:** «обзор неточен» → пояснить источник данных
- **Честные ограничения:** обзор нуждается в плане и минимум 3 рефлексиях. v1 — без интеграций (ввод в боте)

## 7) Positioning Triangle

- **Персонаж:** фаундер-сольщик, который планирует неделю, но не измеряет движение
- **Альтернатива:** ручной weekly review, дневники, «держу в голове». Работает редко
- **Угол атаки:** бот с тремя диалогами (план + рефлексия + обзор) и GPT-анализом план vs факт
- **Доказательство:** план в воскресенье → факты из рефлексии → обзор «план vs факт»

## 8) Monetization Ladder

- **Free:** недельное планирование + ежедневная рефлексия (до 5 вопросов) + недельный обзор. Ограничение: без истории и трендов
- **L1 — Founder ($9/мес):** история 3 месяца, расширенный обзор, тренды
- **L2 — Team ($19/мес):** + shared plan для команды, общий обзор
- **Unit:** неделя с измеряемым движением — план, рефлексии, обзор
- **Почему честно:** free даёт полный цикл. Платишь за историю и команду

## 10) Metric Dashboard

- **North Star:** % недель с полным циклом (план + ≥3 рефлексии + обзор просмотрен)
- **Activation:** первый недельный обзор (пользователь увидел план vs факт)
- **Conversion:** Free → L1 — когда история 2 недель заканчивается и хочется видеть тренды
- **Retention:** Completion рефлексии D7 >40%, D30 >25%. Просмотр обзора D7 >60%
- **Time-to-Wow:** первый обзор — «вот план, вот факт»
- **Качество обзора:** % обзоров с чётким план vs факт (измеримое движение)
- **LLM-метрики:** cost на пользователя/неделю, latency p95, % fallback
- **Вопрос (при оттоке):** «Что помешало? (а) рефлексия отнимает время (б) обзор нерелевантен (в) другое»

## Product Decisions

1. **Три потока обязательны:** недельное планирование (вход), ежедневная рефлексия (данные), недельный обзор (выход). Без рефлексии — обзор слабее
2. **Недельное планирование:** бот задаёт вопросы (где пользователь сейчас, главный фокус, измеримый результат, почему важно, что отвлекает, главный риск). GPT возвращает план. Сохраняется для обзора. Промпт: `WEEKLY_PLAN_SYSTEM_PROMPT.md`
3. **Ежедневная рефлексия:** короткие вопросы. Две ветки после «Было ли движение по главному?» — Да/Нет. GPT возвращает ответ. Промпт: `DAILY_REFLECTION_SYSTEM_PROMPT.md`
4. **Недельный обзор:** бот собирает план + рефлексии по схеме `WEEKLY_REVIEW_INPUT_SCHEMA.JSON`. GPT возвращает (промпт: `WEEKLY_REVIEW_SYSTEM_PROMPT.md`): главный фокус, статус результата (достигнут / частично / не достигнут), что реально сработало (1–3 сдвига), узкое место недели, управленческий вывод
5. **Минимум данных для обзора:** ≥1 план + ≥3 рефлексии. Иначе — предупреждение
6. **Канал:** Telegram первичен. Напоминания настраиваемые
7. **llm_calls логируются** — модель, токены, latency, trace_id
8. **MVP — без интеграций.** Ввод в боте
9. **Угол атаки:** измерение движения по плану. Фичи не из этой цели — не в MVP

## Glossary

- **Фаундер:** основатель стартапа (сольщик или ранний софаундер)
- **Недельное планирование:** воскресенье. Вопросы → GPT-план. `WEEKLY_PLAN_SYSTEM_PROMPT.md`
- **Ежедневная рефлексия:** каждый день. Вопросы → GPT-ответ. `DAILY_REFLECTION_SYSTEM_PROMPT.md`. Данные → обзор
- **Недельный обзор:** суббота. Вход: `WEEKLY_REVIEW_INPUT_SCHEMA.JSON` (план + рефлексии). Промпт: `WEEKLY_REVIEW_SYSTEM_PROMPT.md`. Выход: фокус, статус результата, что сработало, узкое место, вывод
- **Unit:** неделя с полным циклом — план, рефлексии, обзор
- **llm_call:** вызов GPT. Логируется
