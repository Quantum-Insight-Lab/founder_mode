**Тип контента:** лонгрид с научной аргументацией, целевая аудитория — предприниматели, технари, люди в теме продуктивности и саморазвития

## Часть 1. Посев в VK AdBlogger

### 1.1 Регистрация и подготовка кабинета

1. Зайти на [adblogger.vk.ru](https://adblogger.vk.ru) через VK ID
2. Выбрать статус **«Рекламодатель»**
3. Указать реквизиты: ИП / ООО / самозанятый (обязательно — без этого нельзя пополнить баланс)
4. Пополнить баланс — минимум 100 ₽ с НДС; для первого теста рекомендуется 10 000–30 000 ₽
5. Дождаться активации кабинета (обычно 1 рабочий день)

> ⚠️ Оплата — строго по безналу через выставление счёта. Наличные и карты физлица не принимаются.

### 1.3 Креативы для посева

Пост — это научный лонгрид с сильным открывающим тезисом и несколькими неочевидными поворотами. Задача посевного объявления — **создать зуд, а не пересказать**. Человек должен хотеть дочитать, а не думать, что уже всё понял.

Форматы: текст + изображение (основной), клип (дополнительный).

#### Клип-формат (опционально)

Если есть возможность записать видео (60–90 секунд):

**Структура:**
1. Крючок (0–5 сек): «Почему чем умнее фаундер — тем хуже у него с продажами?»
2. Тезис (5–20 сек): один парадокс из поста — например, про перфекционизм и два его вида с противоположными эффектами
3. Разжигание (20–50 сек): «В посте разобрали 4 механизма + что реально работает»
4. CTA (50–90 сек): «Ссылка в описании» или текст на экране

### 1.4 Настройка кампании в AdBlogger — пошагово

1. **Создать кампанию:** Кабинет → «Посевы» → «Создать кампанию»
2. **Название кампании:** например, `Прокрастинация-фаундеры-тест-апрель`
3. **Загрузить креатив:** текст + изображение (рекомендуемый размер — 1200×675 px, JPG/PNG)
4. **Добавить ссылку** на пост в сообществе (`vk.com/club237425211?w=wall-...`)
5. **Включить авто UTM-метки** — обязательно, чтобы потом видеть, какое сообщество дало какой результат
6. **Подобрать сообщества** через каталог → фильтры по тематике, охвату, географии
7. **Создать группы площадок** (например: «Стартапы», «Психология», «IT») — это удобнее для сравнения результатов
8. **Отправить заявки** в выбранные сообщества (владельцы принимают в течение 1–3 рабочих дней)
9. **Маркировка** — происходит автоматически, токен erid генерируется платформой

> 💡 Совет: запускайте разные варианты текста (A, B, C) в разных группах сообществ одновременно — так сразу увидите, какой угол работает лучше.

### 1.5 Аналитика посева

После публикаций в отчёте AdBlogger смотрите:

| Метрика | На что обращать внимание |
|---|---|
| **Охват** | Уникальные пользователи, увидевшие пост |
| **CPM** | Стоимость 1000 показов — для сравнения площадок |
| **Клики** | Переходы по ссылке на пост |
| **CPC** | Стоимость клика — главная метрика эффективности |
| **CTR** | Клики / показы — насколько цепляет креатив |

**Что делать с данными:**
- Сообщества с CPC ниже среднего → занести в список для повторных размещений
- Сообщества с охватом выше, но CTR ниже → проверить соответствие аудитории
- Вариант текста с лучшим CTR → использовать как основу для таргета

## Часть 3. Связка посев + таргет — стратегия

### Последовательность запуска

```
Неделя 1
├── Запустить посев в 15–25 сообществах (3 варианта текста)
└── Параллельно: запустить таргет — группы «Интересы» и «Ключевые слова»

Неделя 2
├── Проанализировать результаты посева: лучшие площадки и лучший текст
├── Отключить неэффективные объявления в таргете
└── Масштабировать: добавить новые сообщества в AdBlogger + увеличить бюджет на рабочие группы

Неделя 3+
├── Повторный посев в лучших сообществах (можно тем же текстом через 3–4 недели)
└── Look-alike кампания в таргете (если набралась аудитория пикселя/базы)
```

### Чем отличаются каналы и зачем оба

| | AdBlogger (посев) | VK Реклама (таргет) |
|---|---|---|
| **Роль** | Охват и доверие через «чужой» голос | Точечный трафик на целевую аудиторию |
| **Восприятие** | Нативный пост — выше доверие | Явная реклама — ниже доверие |
| **Запуск** | 1–3 дня на модерацию площадки | Быстро — после проверки объявления |
| **Оптимум** | 15–50 площадок за раз | 3–5 групп объявлений |
| **Аналитика** | По площадкам (какой паблик сработал) | По аудиториям и объявлениям |
| **Виральность** | Высокая (репосты из паблика) | Низкая |

**Главное правило связки:** текст, который лучше всего зашёл в посеве по CTR → берём его как основу объявления в таргете. Посев — это A/B тест за реальные деньги на живой аудитории.
